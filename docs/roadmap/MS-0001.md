# M0: Foundations

## Goal

Foundations: conventions, indexes, contributing and roadmap as entities.

## Delivers

- The Convention and Milestone entity types; Task gains a `milestone` relation.
- The first conventions (`docs/contributing/`).
- An `_index.md` in every `docs/` directory, from a temporary generator; `entitycheck` verifies each index against its files.
- Root `CONTRIBUTING.md` and `ROADMAP.md` that point to their indexes.
- Legacy names removed: the language is simply "the DSL", and axiom paths use `.axiom/` (TASK-0015).

## Exit Criteria

- Every entity and every index is valid according to `entitycheck`.
- The conventions are Active.
- An independent review accepts TASK-0015 and TASK-0016.
