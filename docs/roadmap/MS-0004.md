# M3: Interpreter

## Goal

Interpreter: a stateless step engine.

## Delivers

- An explicit program counter and frame stack, serialised to `.axiom/run.json`.
- Next steps as commands to the agent, and results as events from the agent.
- Outcomes, WHEN, LOOP, FORK/JOIN, BREAK, FALLBACK/STOP and entity transitions, through the entity core.
- The ledger writer (`.axiom/ledger.jsonl`).

## Exit Criteria

- Golden tests: given the scripted events, it reproduces the expected traces of the lab scenarios.
- It handles the Test 3 DANGER cases (E03 and N06) correctly by construction.
