# M1: DSL core in `runtime/axiom/dsl/`

## Goal

DSL core in `runtime/axiom/dsl/`: lexer, AST, parser and validity rules.

## Delivers

- A token enum, and a scanner lexer with INDENT/DEDENT tokens and token positions.
- Frozen dataclass AST nodes, and a recursive-descent parser that recovers in panic mode.
- Notification-style diagnostics, a visitor, a symbol table, and one `Rule` class per V1–V12 in a registry.
- The facade `axiom.dsl.check()` and the CLI command `axiom check`.

## Exit Criteria

- The differential test shows zero disagreement with `lab/tools/dslcheck.py` on the spec examples, the lab scenarios and the probe-authored programs.
- `mypy --strict` is clean and all tests pass.
