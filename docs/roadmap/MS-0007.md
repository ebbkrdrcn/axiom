# M6: DSL v4

## Goal

DSL v4.

## Delivers

- `ASK` replaces `HITL`, with role targets and `answered: … by …` (ADR-0016).
- `DELEGATE … TO <actor>` with a FALLBACK.
- Protocol parameters.
- Extra text in an answer is context, not an outcome.
- F-61…F-63 move into the runtime.
- Review → Done is split (TASK-0014).

## Exit Criteria

- The parser, the interpreter and the protocols are updated.
- A small lab validation run on Sonnet passes.
