# M4: MCP server, CLI, `AGENT.md` and hooks

## Goal

MCP server, CLI, `AGENT.md` and hooks.

## Delivers

- MCP tools:
  - protocols, actors and types by name;
  - `start_run`, `next_step` and `report_result`;
  - `create_entity`, `update_entity` and `transition`, which also update the index and the ledger;
  - `rebuild_index`.
- `axiom project start <path>`, which leaves `AGENT.md`, creates the `docs/` skeleton and updates `.gitignore`.
- A PreToolUse hook that blocks direct writes to entity files, `_index.md` files and `status:` lines.
- A pinned, stable axiom version for execution.

## Exit Criteria

- A session in a scratch project runs `task-delivery` through MCP from start to end, with scripted answers.
