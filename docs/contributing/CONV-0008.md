# File paths about a project are relative to its root

## Rule

Every file path that axiom states, reads or returns about a project is relative to that project's root, and axiom content is referenced by name.

## Rationale

The agent works in the target project. Axiom's own location must never leak into it (ADR-0021).

## How to check

Look at the paths in `rules/` and in runtime output. None is absolute, and none points into axiom's own tree. Protocols, actors and types are requested by name.

## Examples

Good: `docs/tasks/TASK-0100.md`. Bad: `/home/user/axiom/rules/types/task/template.md` returned to an agent.
