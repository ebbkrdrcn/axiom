# The runtime core uses only the Python standard library

## Rule

The runtime core uses only the Python standard library; only `runtime/axiom/mcp/` may import the MCP SDK.

## Rationale

The core is the deterministic heart of axiom. Fewer dependencies mean fewer failure modes, easier pinning of stable versions (ADR-0021), and no supply-chain surprises.

## How to check

Look at every `import` in `runtime/axiom/` outside `mcp/`. Each imported top-level module is in the standard library (`sys.stdlib_module_names`) or is `axiom` itself. `tests/test_stdlib_only.py` performs this check.

## Examples

Good: `from dataclasses import dataclass`. Bad: `import lark` in `runtime/axiom/dsl/parser.py`.
