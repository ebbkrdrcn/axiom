# All code under `runtime/` passes `mypy --strict`

## Rule

All code under `runtime/` passes `mypy --strict`.

## Rationale

Types document the interfaces between layers and catch mistakes before tests run. Strict mode leaves no untyped escape hatches.

## How to check

Run `mypy --strict runtime/`. It reports no errors.

## Examples

Good: `def check(source: str) -> CheckResult:`. Bad: `def check(source):`.
