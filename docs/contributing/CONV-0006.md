# AST nodes are frozen dataclasses that carry their source position

## Rule

AST nodes are frozen dataclasses that carry their source position.

## Rationale

An immutable tree can be shared by the validators and the interpreter without defensive copies. Positions make every diagnostic precise.

## How to check

Every AST node class is declared with `@dataclass(frozen=True)` and has `line` and `column` fields.

## Examples

Good: `@dataclass(frozen=True) class Loop(Node): name: str; body: tuple[Node, ...]`.
