# No module holds mutable global state

## Rule

No module holds mutable global state; state is passed explicitly or lives in objects.

## Rationale

Axiom is stateless and serves many sessions (ADR-0021). Hidden global state breaks determinism and makes tests order-dependent.

## How to check

Check each module's top level. Only constants, pure functions, classes, and immutable tables (for example a `frozenset` or a `MappingProxyType`) are defined there. A module-level `list`, `dict` or `set` that is mutated later is a violation.

## Examples

Good: `KEYWORDS: Final = frozenset({"LOOP", "WHEN"})`. Bad: `_cache = {}` filled by a function.
