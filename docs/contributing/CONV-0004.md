# Every runtime layer has its own tests under `tests/`

## Rule

Every runtime layer has its own tests under `tests/`, and all tests pass.

## Rationale

Each layer (lexer, parser, rules, entities, interpreter) must be trustworthy on its own before the layer above relies on it.

## How to check

Run `python3 -m pytest tests/`. Every test passes. Each package in `runtime/axiom/` has a matching test module in `tests/`.
