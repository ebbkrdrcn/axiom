# Every runtime package has its own test directory

## Rule

For every directory `runtime/axiom/<p>/` that contains an `__init__.py`, the directory `tests/<p>/` contains at least one `test_*.py` file.

## Rationale

Each layer must be trustworthy on its own before the layer above relies on it.

## How to check

Run the command below from the repository root. It prints each package that has no tests and exits with 1 if there is one; no output and exit 0 means compliance.

```sh
rc=0; for i in runtime/axiom/*/__init__.py; do [ -e "$i" ] || continue; p=$(basename "$(dirname "$i")"); ls tests/"$p"/test_*.py >/dev/null 2>&1 || { echo "no tests: $p"; rc=1; }; done; exit $rc
```

## Examples

Good: `runtime/axiom/dsl/__init__.py` and `tests/dsl/test_lexer.py`. Bad: `runtime/axiom/entities/__init__.py` with no `tests/entities/` directory.
