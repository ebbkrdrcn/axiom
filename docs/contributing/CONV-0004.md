# Every runtime package has its own tests, and all tests pass

## Rule

Every package directly under `runtime/axiom/` (a layer, for example `dsl`, `entities`, `interpreter`, `mcp`) has its own tests under `tests/<package>/`, and `python3 -m pytest tests/` passes.

## Rationale

Each layer must be trustworthy on its own before the layer above relies on it.

## How to check

1. Run `python3 -m pytest tests/`. It must report no failures.
2. List the packages with `ls -d runtime/axiom/*/`. For each package `<p>`, confirm that `tests/<p>/` exists and contains at least one `test_*.py` file.

A script that automates step 2 may be added later. The check then becomes `mechanical`.
