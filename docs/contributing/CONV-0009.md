# Entity files and `_index.md` files change only through axiom's entity operations

## Rule

Entity files and `_index.md` files change only through axiom's entity operations; until the MCP server exists, through the index generator, with `entitycheck` passing.

## Rationale

Only then are identities unique and indexes current. Agents rely on `_index.md` to find knowledge.

## How to check

Run `axiom entities check docs` (or its reference, `python3 lab/tools/entitycheck.py --all docs`). Every entity is VALID, and every index matches its files.
