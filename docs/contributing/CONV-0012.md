# The test suite passes before a change is merged to `main`

## Rule

`python3 -m pytest tests/` reports no failures on every commit merged to `main`.

## Rationale

A red suite on `main` hides new failures behind old ones, and the next layer cannot trust the one below it.

## How to check

Run `python3 -m pytest tests/` on the commit to be merged. Exit status 0 means compliance; exit status 5 (no tests collected) also counts as compliance while `tests/` holds no test files.

## Examples

Good: a merge whose commit passes the suite. Bad: merging a commit that has a failing test and fixing it "in the next commit".
