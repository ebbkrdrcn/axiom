# A Task moves to Done only after an independent review by an agent that did not do the work

## Rule

A Task moves to Done only after an independent review by an agent that did not do the work, with the verdict recorded in the Task's Notes.

## Rationale

Whoever does the work must not verify it. People do not review internal work (ADR-0018), so an independent verifier stands in until TASK-0014 settles the precondition.

## How to check

The Task's Notes contain the reviewer's verdict (`accepted`), evidence for each item, and a statement that the reviewer did not do the work.
