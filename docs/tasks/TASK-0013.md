# Restructure the repository into the axiom layout

## Description

Apply ADR-0021 to this repository:

- move the specs to `spec/`;
- move the entity types to `rules/types/`;
- move the protocols to `rules/protocols/`;
- keep axiom's own ADRs and Tasks in `docs/`;
- rename `dsl-lab/` to `lab/`;
- add placeholders for `rules/actors/`, `runtime/`, `templates/` and `tests/`;
- update every reference.

Representation paths are relative to the target project's root.

## Acceptance Criteria

- The top-level directories are `spec/`, `rules/`, `runtime/`, `templates/`, `tests/`, `lab/` and `docs/`, and nothing else remains of `entities/` or `dsl-lab/`.
- `rules/types/*/representation.md` state instance paths under `docs/`, relative to the target project's root.
- `python3 lab/tools/entitycheck.py docs/adr/*.md docs/tasks/*.md` reports every file VALID.
- `python3 lab/tools/dslcheck.py --md spec/dsl.md` reports every example `ok`, and `rules/protocols/task-delivery.dsl` is VALID.
- `README.md`, `VISION.md`, `lab/STATUS.md` and `lab/NEXT.md` point to the new locations.
- `.gitignore` excludes `.axiom/run.json`.
