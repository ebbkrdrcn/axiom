# Reconcile ADR-0001 with ADR-0021

## Description

ADR-0001 says that the agent is the interpreter of the DSL and that no program performs control flow on its behalf. ADR-0021 makes axiom the interpreter: axiom drives the process, and the model makes the judgements the process requires. Independent review 2 of TASK-0015 found the conflict.

- Decide with the owner whether ADR-0001 becomes Superseded by ADR-0021, or is amended to cover only the judgement steps.
- Apply the decision, and make every reference to ADR-0001 in `spec/` consistent with it.

## Acceptance Criteria

- ADR-0001 and ADR-0021 no longer contradict each other on who interprets the DSL.
- If ADR-0001 is Superseded, it names ADR-0021 as its successor.
- `python3 lab/tools/entitycheck.py --all docs` reports no errors.
