# Entity Model: define status conditions

## Description

`entity-model.md` leaves open how a WHEN tests an entity's current status. The syntax must not look like an outcome condition (`t1.accepted`).

## Acceptance Criteria

- An ADR proposes the syntax and semantics.
- `dsl.md` and `dslcheck.py` implement the accepted proposal.
