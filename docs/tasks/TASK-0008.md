# Small spec gaps from Test 2

## Description

Low-priority gaps found in Test 2: the link between `VERIFY x` and `DELEGATE x` (F-45), when the runtime stops waiting for a HITL (F-46), and HITL names equal to EMIT names (F-47).

## Acceptance Criteria

- `dsl.md` states that `VERIFY x` evaluates the result named `x`, and that a `DELEGATE` with the same name is not required.
- `dsl.md` states that when to stop waiting for a HITL is decided by the runtime.
- V7 states whether a HITL name may equal an EMIT artifact name.
