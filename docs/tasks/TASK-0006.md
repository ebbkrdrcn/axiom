# FORK: align the FORK table with V3

## Description

The FORK table says every BREAK in a branch is INVALID, while BREAK and V3 allow a BREAK that leaves a LOOP nested inside the same branch (F-50).

## Acceptance Criteria

- The FORK table, the Quick reference and the BREAK section state the same rule as V3.
- `dsl.md` contains a `text` example with a LOOP and BREAK nested inside one FORK branch, and the checker accepts it.
