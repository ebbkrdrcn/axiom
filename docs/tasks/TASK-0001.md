# HITL: map paraphrased answers with extra feedback

## Description

A human response that clearly means one listed answer but adds comments (for example "Not like this, rewrite the intro.") was classified as insufficient by all Haiku probes in Test 2 (S12, F-36).

## Acceptance Criteria

- `dsl.md` HITL states that a response which clearly means one listed answer counts as that answer, even if it adds comments or requests.
- The HITL section contains at least two examples of paraphrased answers with their classification.
- S12 passes for Haiku in the next test.
