# WHEN: make the next step after a false WHEN explicit

## Description

After a false `WHEN` that ends a LOOP body, a Haiku probe continued with the next line of text outside the loop (S20-h2, F-38). Rule 7 is also misapplied when another outcome is already established (F-48).

## Acceptance Criteria

- Execution rule 2 says: false → continue with the next statement in the same block; if the WHEN was the last statement of a loop body, the loop body starts again.
- Rule 7 states that an established other outcome also makes the WHEN false.
- S20 and S10 pass for Haiku in the next test.
