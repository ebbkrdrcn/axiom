# Remove the legacy "DSL" name: the language is simply "the DSL"

## Description

The independent review of TASK-0013 found names that predate axiom. The owner decided that the language is simply called "the DSL", without a product prefix.

- Remove "DSL" from `spec/dsl.md`, `spec/entity-model.md`, `lab/tools/dslcheck.py`, `lab/findings.md` and `docs/adr/ADR-0001.md`.
