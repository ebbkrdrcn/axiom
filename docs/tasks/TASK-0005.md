# Validity: cover every malformed line and annotate invalid examples

## Description

A line that matches no statement form (for example `BREAK release`) has no rule number (F-42), and the `invalid` examples in `dsl.md` do not name the rules they break (F-43).

## Acceptance Criteria

- V1 covers a line that matches no statement form.
- Every `invalid` block in `dsl.md` is followed by the list of rules it breaks.
- `dslcheck.py --md dsl.md` passes.
