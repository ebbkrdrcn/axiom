# V10: state that it is checked on the program text

## Description

V10 can be read statically or dynamically; a FORK without a JOIN makes its outcomes untestable for the rest of the program (F-51).

## Acceptance Criteria

- V10 states that it is judged on the program text: a WHEN after an un-joined FORK in the same flow may not test outcomes its branches establish.
- The Outcomes section uses the same wording.
