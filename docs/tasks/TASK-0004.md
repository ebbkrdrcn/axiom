# Trace protocol: close the remaining gaps

## Description

The trace format leaves several conventions to examples (F-39, F-40, F-41, F-49).

## Acceptance Criteria

- The trace starts with a validation line (for example `0. validate -> VALID`), or lists the broken rules and stops.
- The first entry into a LOOP is stated to produce no trace line.
- The line form for an AUTO HITL answered by the agent is defined and shown in an example.
- It is stated that `stop` is the last line and `end` is used only for a normal end.
- The Complete example trace follows all of these rules.
