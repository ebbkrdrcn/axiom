# Entity test: first test with entities

## Description

The first test of the Entity Model and the DSL Entities section, run against a frozen copy of `docs/`.

## Acceptance Criteria

- A frozen snapshot of `docs/` is stored under `lab/`, and probes see only that snapshot.
- The scenarios cover: binding success, type mismatch, duplicate identity, relation binding, VERIFY with evidence, undecidable VERIFY, a permitted and a forbidden TRANSITION, a `human:` precondition, and re-reading after DELEGATE.
- Sonnet and Haiku probes are graded by critics, and the report is approved by the owner.
