# Minimum supported model: Claude Haiku 4.5

## Context

The goal is a DSL that even small models follow with close to 100% accuracy. The target model sets how explicit the spec must be.

## Decision

Claude Haiku 4.5 is the minimum supported model. A spec change is accepted only if Haiku probes meet every expected item of the test corpus with zero DANGER errors (the agent deciding for a human, or a skipped fallback). Sonnet is tested alongside as a reference.

## Consequences

- Every test runs Haiku probes, and exit criteria are defined on Haiku results.
- Wording is chosen for literal readers: tables, fixed vocabularies, one rule per sentence.

## Alternatives Considered

- Sonnet as minimum: easier to satisfy, but it does not meet the goal.
- A smaller or non-Claude model: not measurable in the current environment.
