# BREAK does not cross a FORK branch

## Context

A BREAK inside a FORK branch that leaves an enclosing loop raised three incompatible readings (F-08, S11, DP-5).

## Decision

`BREAK` inside a FORK branch is INVALID when the `LOOP` it would leave is outside that branch (V3). To leave a loop based on a branch result, `JOIN` first and then use `WHEN … → BREAK`. A BREAK that leaves a LOOP nested inside the same branch is valid.

## Consequences

- There are no cancellation semantics for concurrent branches.
- Open: the FORK table must state the same exception as V3 (F-50).

## Alternatives Considered

- BREAK cancels the sibling branches (DP-5 B), or marks the loop for exit (DP-5 C).
