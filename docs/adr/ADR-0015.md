# A recursive responsibility tree of supervisors and actors, driven by human intent

## Context

The DSL has been tested with one agent that writes a program and executes it. The intended system is larger than that:

- A human states an intent in natural language.
- Agents turn that intent into work and delegate it.
- Each agent follows a defined process.

## Decision

- **Single entry point.** The only input is a human intent in natural language. The human is always at the top of the tree.
- **Supervisor.** A supervisor receives an intent, splits it into sub-tasks, and creates an Actor for each one. A supervisor can have supervisors below it, so the structure is recursive. Every node is responsible for its subtree.
- **Actor.** An Actor is a Role (for example "Python developer") together with a Protocol and the Context it needs.
- **Protocol.** A Protocol is a DSL program that defines what the Actor does in the process.
- **Context.** A supervisor prepares a context package for each Actor. ADR-0017 describes how.

## Consequences

- The DSL has two kinds of user: the supervisor writes protocols, and actors execute them. Actors may run on smaller models, so execution determinism matters again.
- Protocol and Actor (Role) become entity types. Role definitions carry the authority used by `AUTO` and `ASK` (ADR-0016).
- Open questions:
  - how `DELEGATE` names an Actor;
  - whether a protocol can call another protocol;
  - whether protocols come from an approved library or can be written per task.

## Alternatives Considered

- One agent executing everything: this does not scale to large intents and mixes roles.
