# DELEGATE completes when the result is delivered

## Context

Whether the next statement waits for delegated work was undefined (F-16, DP-7).

## Decision

A `DELEGATE` statement is done when the actor has delivered its result; the next statement starts only then. Concurrency is expressed only with `FORK`. A delivered result is not verified; `VERIFY` evaluates it. Delegated work may change an entity's data only as its Definition permits, and never its status.

## Consequences

- Execution order is fully sequential outside `FORK`.

## Alternatives Considered

- Fire-and-forget DELEGATE (DP-7 B).
