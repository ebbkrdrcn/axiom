# AUTO is a same-line prefix of one decision HITL

## Context

v1 had no AUTO syntax (F-01, F-02). In iteration 1, three probes wrote three different forms. The AUTO experiment showed that placement matters less than documentation.

## Decision

`AUTO` is written directly before a decision `HITL:<name>[…](…)`, on the same line, and applies only to it. The agent answers only if the decision is certain and within its authority; otherwise the human is asked, exactly as without AUTO. AUTO never contains a flow, and AUTO on anything else is INVALID (V5).

## Consequences

- AUTO's scope is always exactly one line, so it cannot silently authorise other decisions.
- Open: the defining sentence must also mention authority (F-37).

## Alternatives Considered

- A `→ AUTO` line under the HITL, a standalone AUTO line, or an AUTO scope (DP-1 B, C and D).
