# Spec quality is measured by blind probes, critics and a linter

## Context

Changes to the spec need evidence that models actually read it as intended.

## Decision

Each test gives blind probes (Sonnet and Haiku; each sees only the spec and one task) a fixed scenario corpus with expected items. Critic agents grade the answers against the spec and tag errors, including DANGER. `dslcheck.py` judges syntax. Every test ends with a report, and the owner approves before the next test or spec change. The work lives in `lab/`.

## Consequences

- Results are comparable across iterations: pass rate per model, D-items, DANGER count.
- Scenario wording errors are corrected and reported separately from spec defects.

## Alternatives Considered

- Manual review only: not repeatable.
