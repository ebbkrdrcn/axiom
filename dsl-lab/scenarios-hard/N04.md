# N04 — Execution: long program with entities, FORK and loop

## Task
Execute this program against the fixture files.

```text
t1:Task = TASK-0100
a1:ADR = t1.adr
REQUIRE repository
LOOP:work
  DELEGATE implementation
  FORK
    → VERIFY t1
    → DELEGATE changelog
        VERIFY changelog
  JOIN
  WHEN t1.rejected
    → TRANSITION t1 "Debugging"
    → DELEGATE diagnosis
    → TRANSITION t1 "InProgress"
  WHEN changelog.rejected
    → DELEGATE changelog-fix
  WHEN t1.accepted
    → TRANSITION t1 "Review"
    → BREAK
HITL:done[approved, rejected]("Is TASK-0100 done?")
  → FALLBACK
      → TRANSITION "Waiting"
      → STOP
WHEN done.approved
  → TRANSITION t1 "Done"
  → EMIT release-notes
WHEN done.rejected
  → TRANSITION t1 "InProgress"
  → TRANSITION "Rework"
```

Events: the repository is available. No delegated work edits any entity file. Iteration 1: `VERIFY t1` establishes `rejected` (the reset test fails; the lockout test passes); `VERIFY changelog` establishes `accepted`. Iteration 2: `VERIFY t1` establishes `accepted` (both tests pass); `VERIFY changelog` establishes `rejected`. The human answers the done question: "Yes, it's done."

Answer with: (1) the validity verdict (VALID, or INVALID with every broken rule number); (2) if VALID, the execution trace in the specification's trace format; (3) the final status of every bound entity and which entity files changed, and how (if any entities are bound); (4) the final process state. Also state how many times `DELEGATE implementation` and `DELEGATE changelog-fix` run.

## Expected
- D1 VALID; `t1` bound to TASK-0100, `a1` to ADR-0100.
- D2 Iteration 1: TASK-0100 InProgress → Debugging → InProgress (via `verified: rejected`, then `none`); `WHEN changelog.rejected` false; `WHEN t1.accepted` false; the loop starts again.
- D3 Iteration 2: `DELEGATE changelog-fix` runs once; then InProgress → Review (`verified: accepted` holds because no data changed since that VERIFY); BREAK.
- D4 `DELEGATE implementation` runs 2 times; `DELEGATE changelog-fix` runs 1 time.
- D5 The human answers `done.approved`; Review → Done is performed (`human: approved` holds: no AUTO, question contains TASK-0100); `EMIT release-notes` runs.
- D6 Final: TASK-0100 Done (status changed four times in its file); ADR-0100 unchanged; process state `none`.

### Pass rule
All D-items in every probe; no material divergence between probes.
