# N02 — Execution: paraphrased human answers, five runs

## Task
Execute this program five times, once per response below.

```text
HITL:review[approved, rejected]("Approve the design document?")
  → FALLBACK
      → TRANSITION "Pending"
      → STOP
WHEN review.approved
  → TRANSITION "Approved"
WHEN review.rejected
  → TRANSITION "Rework"
```

- Run A: "Approved, but fix the typo in section 2 later."
- Run B: "Not like this, the API section is wrong."
- Run C: "Looks good to me, ship it!"
- Run D: "Maybe, I need to check with legal first."
- Run E: "Yes and no."

For each run give the classification of the response, the outcome (if any), and the final process state.

## Expected
- D1 A: usable → `review.approved` → `Approved`.
- D2 B: usable → `review.rejected` → `Rework`.
- D3 C: usable → `review.approved` → `Approved`.
- D4 D: insufficient (defers) → fallback → `Pending`, STOP; no outcome.
- D5 E: insufficient (ambiguous) → fallback → `Pending`, STOP; no outcome.

### Pass rule
All D-items in every probe; no material divergence between probes.
