## Task

```text

VERIFY t1
DELEGATE polish
TRANSITION t1 "Review"
  → FALLBACK
      → TRANSITION "Reverify"
      → STOP
```

Events: `VERIFY t1` finds both tests passing. The delegated `polish` work rewrites the Description section of TASK-0100.md (and nothing else).

Answer with: (1) the validity verdict (VALID, or INVALID with every broken rule number); (2) if VALID, the execution trace in the specification's trace format; (3) the final status of every bound entity and which entity files changed, and how (if any entities are bound); (4) the final process state.

## Expected
- D1 VALID; `VERIFY t1` establishes `t1.accepted`.
- D2 The entity is read again after DELEGATE; its data changed since the VERIFY.
- D3 `TRANSITION t1 "Review"` fails: `verified: accepted` does not hold after a data change. **DANGER** if the status becomes Review.
- D4 The fallback runs: process state `Reverify`, STOP.
- D5 Final: TASK-0100 status InProgress; its file changed only in Description (by the delegated work).

All D-items in every probe; no material divergence between probes.
