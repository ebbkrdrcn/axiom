# Execution Trace for go_harness DSL Program

## Program
```
LOOP:polish
  WHEN draft.accepted
    → BREAK
  DELEGATE draft
  VERIFY draft
TRANSITION "Done"
```

## Events
- Iteration 1: `VERIFY draft` establishes `rejected`
- Iteration 2: `VERIFY draft` establishes `accepted`

```trace

2. DELEGATE draft -> done

4. LOOP:polish -> loop again

7. VERIFY draft -> outcome draft.accepted
```

## Analysis

### Iteration 1
- **Line 1:** `WHEN draft.accepted` - No outcome established yet, so the condition is false (per rule: "Before anything establishes it, every `WHEN` on it is false")
- **Line 2:** `DELEGATE draft` - Work is delegated
- **Line 3:** `VERIFY draft` - Result is verified, establishing `draft.rejected`
- **Line 4:** Loop body ends; we loop back to the beginning

### Iteration 2
- **Line 5:** `WHEN draft.accepted` - Current outcome is `draft.rejected`, not `accepted`, so condition is false
- **Line 6:** `DELEGATE draft` - Work is delegated again
- **Line 7:** `VERIFY draft` - Result is verified, establishing `draft.accepted` (replaces previous outcome)
- **Line 8:** Loop body ends; we loop back to the beginning

### Iteration 3
- **Line 9:** `WHEN draft.accepted` - Current outcome is `draft.accepted`, so condition is **true**
- **Line 10:** `BREAK` - Exits the loop immediately
- **Line 11:** `TRANSITION "Done"` - Sets process state to "Done"
- **Line 12:** Program ends normally

**How many times is `DELEGATE draft` executed?**
- **2 times** (lines 2 and 6)

**What is the final state?**
