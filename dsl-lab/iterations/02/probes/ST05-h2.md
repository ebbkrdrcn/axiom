# Execution Trace

```trace
1. WHEN draft.accepted -> false: skip
2. DELEGATE draft -> done
3. VERIFY draft -> outcome draft.rejected
4. LOOP:polish -> loop again
5. WHEN draft.accepted -> false: skip
6. DELEGATE draft -> done
7. VERIFY draft -> outcome draft.accepted
8. LOOP:polish -> loop again
9. WHEN draft.accepted -> true: run flow
10. BREAK -> break
11. TRANSITION "Done" -> state = "Done"
12. (end of program) -> end
```

## Answer

**How many times is `DELEGATE draft` executed?** 2 times

**Final state:** "Done"

## Explanation

The loop begins with no outcomes established, so the first `WHEN draft.accepted` is false (rule: "Before anything establishes it, every `WHEN` on it is false").

- **Iteration 1:** `DELEGATE draft` executes, then `VERIFY draft` establishes `draft.rejected`. The loop restarts.
- **Iteration 2:** `WHEN draft.accepted` is still false (latest outcome is `rejected`). `DELEGATE draft` executes again, then `VERIFY draft` establishes `draft.accepted`. The loop restarts.
- **Iteration 3:** `WHEN draft.accepted` is now true (latest outcome is `accepted`). The flow runs, executing `BREAK` to exit the loop. Then `TRANSITION "Done"` executes, setting the process state to "Done". Execution completes normally.
