# Validation Result

The program is **INVALID** according to rule **V3**.

## Violation Details

Rule V3 states: "`BREAK` is inside a `FORK` branch, and the `LOOP` it would leave is outside that branch"

In the given program:

- The `BREAK` statement is located inside the first branch of the `FORK` (within the security-review branch, specifically nested inside a `WHEN` construct)
- The `LOOP` that `BREAK` would leave is `LOOP:review`
- `LOOP:review` is the parent structure containing the `FORK`, thus outside the branch
- Therefore, the condition for V3 violation is satisfied

## How to Fix

The specification provides guidance: "To leave a loop based on a branch's result, `JOIN` first, then use `WHEN … → BREAK`."

The corrected structure would move the `WHEN` and `BREAK` outside the `FORK`:

```
LOOP:review
  FORK
    → DELEGATE security-review
        VERIFY security-review
    → DELEGATE docs-review
        VERIFY docs-review
  JOIN
  WHEN security-review.rejected
    → BREAK
  TRANSITION "Reviewed"
EMIT review-summary
```

With this structure, the `BREAK` would be at the LOOP body level (not inside a FORK branch), making it valid.
