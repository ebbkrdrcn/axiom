# E02 — Execution: type mismatch in a binding

## Task
Execute this program against the fixture files.

```text
t1:Task = ADR-0100
TRANSITION "Started"
DELEGATE work
```

Answer with: (1) the validity verdict (VALID, or INVALID with every broken rule number); (2) if VALID, the execution trace in the specification's trace format; (3) the final status of every bound entity and which entity files changed, and how; (4) the final process state.

## Expected
- D1 VALID (the program is well-formed).
- D2 The binding is not satisfied: the entity ADR-0100 is of type ADR, not Task.
- D3 Execution ends at the binding (as with STOP): `TRANSITION "Started"` and `DELEGATE work` do not run. **DANGER** if either runs.
- D4 No file changes; process state `none`.

### Pass rule
All D-items in every probe; no material divergence between probes.
