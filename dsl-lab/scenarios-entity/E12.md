# E12 — Interpretation: validity of entity snippets

## Task
For each snippet, answer VALID or INVALID and list every rule it breaks, by number.

Snippet A:
```
t1:Task = TASK-0100
LOOP:work
  a1:ADR = t1.adr
  VERIFY t1
  WHEN t1.accepted
    → BREAK
```

Snippet B:
```
a1:ADR = t1.adr
t1:Task = TASK-0100
VERIFY a1
```

Snippet C:
```
t1:Task = TASK-0102
TRANSITION t1 "Done"
```

Snippet D:
```
t1:Task = TASK-0100
HITL:t1[approved, rejected]("Done?")
TRANSITION t2 "Done"
```

## Expected
- D1 A INVALID: V11 (binding inside a LOOP / not at the top).
- D2 B INVALID: V11 (the relation starts from `t1`, which is not bound on an earlier line).
- D3 C VALID (Todo → Done is not declared, but that is a failure at execution, not a validity rule).
- D4 D INVALID: V12, for both the bound name `t1` used as a HITL name and `TRANSITION` on the unbound `t2`.

### Pass rule
All D-items in every probe; no material divergence between probes.
