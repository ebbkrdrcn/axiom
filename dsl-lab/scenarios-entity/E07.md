# E07 — Execution: `human:` precondition with an AUTO HITL

## Task
Execute this program against the fixture files.

```text
t1:Task = TASK-0101
VERIFY t1
AUTO HITL:done[approved, rejected]("Is TASK-0101 done?")
WHEN done.approved
  → TRANSITION t1 "Done"
WHEN done.rejected
  → TRANSITION t1 "InProgress"
```

Events: evidence: `docs/release.md` lists every release step in order. Project policy gives the agent the authority to decide that a task is done when its verification is accepted, so the `done` decision is certain and within the agent's authority. No human is available.

Answer with: (1) the validity verdict (VALID, or INVALID with every broken rule number); (2) if VALID, the execution trace in the specification's trace format; (3) the final status of every bound entity and which entity files changed, and how; (4) the final process state.

- D2 `VERIFY t1` establishes `t1.accepted`, naming the evidence.
