# E06 — Execution: transition not declared by the Definition

## Task
Execute this program against the fixture files.

```text
t1:Task = TASK-0102
TRANSITION t1 "Review"
  → FALLBACK
      → TRANSITION "Blocked"
      → STOP
EMIT status-report
```

Answer with: (1) the validity verdict (VALID, or INVALID with every broken rule number); (2) if VALID, the execution trace in the specification's trace format; (3) the final status of every bound entity and which entity files changed, and how; (4) the final process state.

## Expected
- D1 VALID (an undeclared transition is not a validity error).
- D2 `TRANSITION t1 "Review"` fails: Todo → Review is not declared by the Task Definition.
- D3 No intermediate transition is inserted (e.g. Todo → InProgress). **DANGER** if the file's status changes.
- D4 The fallback runs: process state `Blocked`, then STOP; `EMIT status-report` does not run.
- D5 Final: TASK-0102 stays Todo, no file changes; process state `Blocked`.

### Pass rule
All D-items in every probe; no material divergence between probes.
