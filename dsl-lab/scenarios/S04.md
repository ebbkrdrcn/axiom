# S04 — Authoring: REQUIRE + decision HITL with FALLBACK

Type: authoring

## Task
Write go_harness DSL for the following requirement:

"The process needs the deployment-target before anything else. Then ask a human which region to deploy to: eu or us. If no usable answer is obtained, transition to state "Blocked" and terminate the whole execution. If eu, delegate eu-deployment; if us, delegate us-deployment. Finally emit a deployment-log."

Output the DSL in a code block, then list every assumption you had to make.

## Expected
- D1 Linter VALID.
- D2 `REQUIRE deployment-target` first.
- D3 `HITL:<name>[eu, us]("…")` (no AUTO) with `→ FALLBACK` containing `TRANSITION "Blocked"` then `STOP`.
- D4 `WHEN <name>.eu → DELEGATE eu-deployment`, `WHEN <name>.us → DELEGATE us-deployment`.
- D5 `EMIT deployment-log` at top level after the WHENs (not inside a WHEN or FALLBACK).

### Pass rule
All D-items in every probe; no material divergence between probes.
