# S05 — Interpretation: validity of four snippets

Type: interpretation

## Task
For each snippet, answer VALID or INVALID and cite the rule (by number if the specification numbers it).

Snippet A:
```
HITL:release[approved, rejected]("Approve release?")
AUTO
  WHEN decision.uncertain
    → HITL("Approve release?")
```

Snippet B:
```
DELEGATE implementation
VERIFY implementation
WHEN implementation.rejected
  → BREAK
```

Snippet C:
```
AUTO HITL:approve[yes, no]("Approve release?")
WHEN approve.yes
  → EMIT release
```

Snippet D:
```
HITL:region[eu, us]("Which region?")
  → FALLBACK
      → TRANSITION "Blocked"
WHEN region.eu
  → DELEGATE eu-deployment
```

## Expected
- D1 A INVALID (V5; `decision.uncertain` also V6).
- D2 B INVALID (V2).
- D3 C VALID.
- D4 D INVALID (V8).

### Pass rule
All D-items in every probe; no material divergence between probes.
