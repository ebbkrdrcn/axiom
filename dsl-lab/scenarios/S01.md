# S01 — Authoring: auto-resolvable merge decision

Type: authoring

## Task
Write go_harness DSL for the following requirement:

"Delegate the implementation and verify it. Then a merge decision is needed: the agent may make the merge decision itself when it is clearly determined by the available information and criteria; otherwise a human must be asked "Merge this change?". If the decision is to merge, transition to state "Merged". If the decision is not to merge, transition to state "Rework"."

Output the DSL in a code block, then list every assumption you had to make.

## Expected
- D1 Linter VALID.
- D2 `DELEGATE implementation` before `VERIFY implementation`.
- D3 `AUTO HITL:<name>[<a>, <b>]("Merge this change?")` with exactly two answers.
- D4 Two WHENs `<name>.<a>` → `TRANSITION "Merged"` and `<name>.<b>` → `TRANSITION "Rework"`.
- D5 No condition on uncertainty; no flow inside AUTO.

### Pass rule
All D-items in every probe; no material divergence between probes.
