# S21 — Execution: WHEN evaluated before its outcome exists

Type: execution trace

## Task
Consider this go_harness DSL:
```
TRANSITION "Testing"
WHEN tests.accepted
  → TRANSITION "Review"
DELEGATE tests
VERIFY tests
EMIT test-report
```
Event: `VERIFY tests` establishes `accepted`.

First give the validity verdict. Then produce the step-by-step execution and the final state. Is `TRANSITION "Review"` ever executed?

## Expected
- D1 The program is VALID.
- D2 The WHEN is checked once before VERIFY (no outcome yet → false) and is never re-checked; "Review" is never executed.
- D3 EMIT test-report runs; final state "Testing".

### Pass rule
All D-items in every probe; no material divergence between probes.
