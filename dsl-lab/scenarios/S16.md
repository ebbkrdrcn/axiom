# S16 — Execution: test loop (baseline)

Type: execution trace

## Task
Consider this go_harness DSL:
```
LOOP:tdd
  DELEGATE implementation
  DELEGATE tests
  VERIFY tests
  WHEN tests.accepted
    → TRANSITION "Review"
    → BREAK
  WHEN tests.rejected
    → TRANSITION "Debugging"
    → DELEGATE diagnosis
EMIT source-code
```
Events: iteration 1: `VERIFY tests` establishes `rejected`; iteration 2: `accepted`.

Produce the step-by-step execution and the final state.

## Expected
- D1 Iteration 1: accepted-WHEN skipped; Debugging; DELEGATE diagnosis; loop again.
- D2 Iteration 2: Review; BREAK; the rejected-WHEN is not evaluated.
- D3 EMIT source-code once; final state "Review".

### Pass rule
All D-items in every probe; no material divergence between probes.
