# X05 — Interpretation: validity of AUTO placements

Type: interpretation

## Task
For each snippet, answer VALID or INVALID and cite the rule.

Snippet 1:
```
AUTO HITL:deploy[yes, no]("Deploy to production?")
WHEN deploy.yes
  → EMIT deployment
```
Snippet 2:
```
AUTO DELEGATE implementation
VERIFY implementation
```
Snippet 3:
```
HITL:deploy[yes, no]("Deploy to production?") AUTO
WHEN deploy.yes
  → EMIT deployment
```
Snippet 4:
```
AUTO
HITL:deploy[yes, no]("Deploy to production?")
```

## Expected
- D1 1 VALID.
- D2 2 INVALID (V5).
- D3 3 INVALID (form; AUTO must come before HITL on the same line).
- D4 4 INVALID (V5).

### Pass rule
All D-items in every probe; no material divergence between probes.
