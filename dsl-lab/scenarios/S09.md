# S09 — Interpretation: undeclared outcome names

Type: interpretation

## Task
Consider this go_harness DSL:
```
DELEGATE implementation
VERIFY implementation
WHEN implementation.passed
  → TRANSITION "Review"
WHEN tests.failed
  → TRANSITION "Debugging"
```
1. Is this program valid? Cite rules.
2. If `VERIFY implementation` is negative, what does an executing agent do?

## Expected
- D1 INVALID: V6 for `implementation.passed` and V6 for `tests.failed`.
- D2 The program is not executed at all (validate first); the agent reports the violations.

### Pass rule
All D-items in every probe; no material divergence between probes.
