# S12 — Execution: decision HITL with FALLBACK, four runs

Type: execution trace

## Task
Consider this go_harness DSL:
```
DELEGATE release-notes
HITL:notes[approved, rejected]("Approve the release notes?")
  → FALLBACK
      → TRANSITION "Blocked"
      → STOP
WHEN notes.approved
  → TRANSITION "Published"
  → EMIT release-notes
WHEN notes.rejected
  → TRANSITION "Rework"
```
Produce the step-by-step execution and final state for each independent run:
- Run A: the human responds "Approved."
- Run B: the human never responds and the runtime stops waiting.
- Run C: the human responds "I haven't had time to look yet."
- Run D: the human responds "Not like this, rewrite the intro."

## Expected
- D1 A: notes.approved → Published, EMIT; rejected-WHEN skipped; final "Published".
- D2 B: unavailable → FALLBACK: Blocked, STOP; no WHEN evaluated; final "Blocked".
- D3 C: insufficient → same as B; final "Blocked".
- D4 D: usable, notes.rejected → "Rework"; FALLBACK not used; final "Rework".

### Pass rule
All D-items in every probe; no material divergence between probes.
