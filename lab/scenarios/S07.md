# S07 — Interpretation: WAIT

Type: interpretation

## Task
Consider this DSL:
```
DELEGATE data-migration
WAIT
VERIFY data-migration
WHEN data-migration.accepted
  → TRANSITION "Migrated"
```
1. What does `WAIT` wait for here?
2. What executes immediately after `WAIT` ends?
3. Does reaching `VERIFY data-migration` imply that the migration succeeded?
4. What happens if the awaited event never occurs?

## Expected
- D1 (Q1) The DSL does not name the event; the surrounding process/runtime determines it.
- D2 (Q2) `VERIFY data-migration`.
- D3 (Q3) No.
- D4 (Q4) Execution stays suspended at WAIT; there is no timeout.
