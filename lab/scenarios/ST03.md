Type: interpretation

## Task
Is this go_harness program valid? If not, list every violated rule with its rule number and line number (line 1 = `REQUIRE repository`). Do not execute it.
```
REQUIRE repository
LOOP:cycle
  DELEGATE implementation
  FORK
    → VERIFY implementation
        WHEN implementation.rejected
          → BREAK
    → DELEGATE review
        VERIFY review

  WHEN review.passed
    → TRANSITION "Reviewed"
  HITL:ship[yes, no]("Ship it?")
    → FALLBACK
        → TRANSITION "Waiting"
  WHEN ship.yes
    → BREAK
EMIT source-code
```
