# S15 — Execution: STOP inside a FORK branch

Type: execution trace

## Task
Consider this DSL:
```
FORK
  → DELEGATE lint
      VERIFY lint
      WHEN lint.rejected
        → STOP
  → DELEGATE docs
      EMIT docs
JOIN
EMIT build
```
Events: `VERIFY lint` establishes `rejected`. At that moment the docs branch has executed `DELEGATE docs` but not `EMIT docs`.

Produce the step-by-step execution. Is `EMIT docs` executed? Is `JOIN` completed? Is `EMIT build` executed?

## Expected
- D1 STOP ends the whole execution including the docs branch.
- D2 EMIT docs: no; JOIN: never completes; EMIT build: no.

### Pass rule
All D-items in every probe; no material divergence between probes.
