# S18 — Execution: FORK without JOIN; DELEGATE completion

Type: execution trace

## Task
Consider this DSL:
```
DELEGATE design
DELEGATE implementation
FORK
  → DELEGATE docs
  → DELEGATE changelog
EMIT release
```
Events: the actor for `design` takes a long time to deliver the design. After the FORK starts, `docs` takes 1 hour and `changelog` takes 5 minutes.

1. Can `DELEGATE implementation` start before the design has been delivered?
2. When is `EMIT release` executed relative to the docs and changelog branches?
3. Is it guaranteed that docs exist when `EMIT release` executes?

## Expected
- D1 (Q1) No: a DELEGATE is done only when the actor delivers.
- D2 (Q2) Immediately after the FORK has started its branches (no JOIN), while they are still running.
- D3 (Q3) No.

### Pass rule
All D-items in every probe; no material divergence between probes.
