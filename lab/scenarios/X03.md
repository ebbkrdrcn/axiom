# X03 — Execution: AUTO, decision determined

Type: execution trace

## Task
Consider this DSL:
```
DELEGATE dependency-upgrade
VERIFY dependency-upgrade
AUTO HITL:merge[approved, declined]("Merge the dependency upgrade?")
  → FALLBACK
      → TRANSITION "Blocked"
      → STOP
WHEN merge.approved
  → TRANSITION "Merged"
WHEN merge.declined
  → TRANSITION "Deferred"
```
Context: the merge criterion is "merge when verification accepts the upgrade and the changelog announces no breaking change". The process gives the agent authority to merge dependency upgrades. `VERIFY dependency-upgrade` establishes `accepted`. The changelog lists only bug fixes. No human is currently online.

Produce the step-by-step execution and the final state. Is a human asked? Is the FALLBACK used?

## Expected
- D1 Determined → the agent establishes merge.approved; no human is asked.
- D2 FALLBACK not used; "Merged"; the declined-WHEN is skipped; final "Merged".
