# ST05 — Stress execution: WHEN before VERIFY inside a loop

Type: execution trace

## Task
Consider this go_harness DSL:
```
LOOP:polish
  WHEN draft.accepted
    → BREAK
  DELEGATE draft
  VERIFY draft
TRANSITION "Done"
```
Events: in iteration 1 `VERIFY draft` establishes `rejected`, in iteration 2 `accepted`.

Produce the step-by-step execution. How many times is `DELEGATE draft` executed? What is the final state?

## Expected
- D1 Iteration 1: WHEN false (no outcome yet); DELEGATE; VERIFY rejected; loop again.
- D2 Iteration 2: WHEN false (latest outcome rejected); DELEGATE; VERIFY accepted; loop again.
- D3 Iteration 3: WHEN true → BREAK; "Done". DELEGATE draft runs 2 times; final "Done".

### Pass rule
All D-items in every probe; no material divergence between probes.
