# S10 — Interpretation: scope of nested lines under →

Type: interpretation

## Task
Consider this DSL:
```
VERIFY review
WHEN review.rejected
  → DELEGATE correction
      VERIFY correction
  → TRANSITION "Rework"
EMIT review-report
```
Assume `VERIFY review` establishes `review.rejected`.

1. Which statements belong to the WHEN flow?
2. Sequential or concurrent, and in what order?
3. Is `VERIFY correction` part of the WHEN flow?
4. Is `EMIT review-report` part of the WHEN flow? Is it executed?
5. If `VERIFY review` had established `review.accepted`, which statements would execute?

## Expected
- D1 Flow = DELEGATE correction, VERIFY correction, TRANSITION "Rework"; sequential in that order.
- D2 EMIT is outside the WHEN and executes afterwards.
- D3 (Q5) VERIFY review, the WHEN is skipped, EMIT review-report.

### Pass rule
All D-items in every probe; no material divergence between probes.
