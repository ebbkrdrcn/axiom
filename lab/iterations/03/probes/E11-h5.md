# E11 Solution: DSL Program

## Program

```
t:Task = TASK-0100
a:ADR = t.adr

LOOP:implement
  DELEGATE implementation
  VERIFY t
    → FALLBACK
        → TRANSITION "Blocked"
        → STOP
  WHEN t.accepted
    → TRANSITION t "Review"
    → BREAK
  WHEN t.rejected
    → TRANSITION t "Debugging"
    → DELEGATE diagnosis
    → TRANSITION t "InProgress"

HITL:done[approved, rejected]("Is TASK-0100 done?")
WHEN done.approved
  → TRANSITION t "Done"
WHEN done.rejected
  → TRANSITION t "InProgress"
```

## Assumptions

1. **No FALLBACK on HITL:done**: If the human does not respond to the question about whether the task is done, execution ends (following DSL rule that an operation without a FALLBACK ends execution if it fails). The requirement does not specify behavior for this case.

2. **Work delegation**: Both "implementation" and "diagnosis" are delegated to an unspecified actor. The program defines what work is needed, not how it is performed.

3. **Verification preconditions**: The Task Definition requires the precondition `verified: accepted` for the InProgress → Review transition, and `verified: rejected` for the InProgress → Debugging transition. These preconditions are automatically satisfied by the VERIFY statement that establishes the outcome immediately before each WHEN.

4. **Human decision boundary**: The HITL:done question is answered by a human without AUTO, which permits the precondition `human: approved` for the Review → Done transition.

5. **Process state vs. entity status**: The `TRANSITION "Blocked"` in the VERIFY fallback sets the process state, not the entity status. This ends execution in a blocked state.

6. **Loop exit**: The loop ends only when `t.accepted` is established (via BREAK), ensuring the implementation is repeatedly attempted until verification succeeds.

7. **Return to InProgress**: When the human rejects the task as done (WHEN done.rejected), the transition back to InProgress is a valid transition according to the Task Definition, which permits Review → InProgress with no precondition.
