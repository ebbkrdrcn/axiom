# DSL Program

## Program

```text
DELEGATE implementation
VERIFY implementation
AUTO HITL:merge[approved, declined]("Merge this change?")
WHEN merge.approved
  → TRANSITION "Merged"
WHEN merge.declined
  → TRANSITION "Rework"
```

## Assumptions

1. **Merge decision proceeds regardless of implementation verification outcome**: The requirement states "Delegate the implementation and verify it. Then a merge decision is needed." The word "Then" indicates the merge decision follows verification in sequence, not conditionally. The DSL proceeds to the merge decision whether `implementation.accepted` or `implementation.rejected` is established.

2. **Answer options for merge decision**: The specification does not provide a predefined list of acceptable answers for the merge decision. I assumed the answer list is `[approved, declined]` to represent the two possible human responses to "Merge this change?"

3. **No fallback for unavailable merge decision**: The requirement does not specify what happens if the human does not respond or if `AUTO` cannot make a certain decision. When `AUTO` cannot determine the decision with certainty, the human is asked (per the specification). If the human response is unavailable and no fallback is provided, execution ends normally (as per rule 8 in the **Execution in ten rules** section).

4. **Process terminates after state transition**: After the merge decision is made and the appropriate state transition occurs (`Merged` or `Rework`), the process ends naturally. The requirement does not specify further actions, and no `STOP` statement is necessary since execution ends after the last statement (per rule 10: **Execution in ten rules**).

5. **"Merge this change?" is the exact human question**: The requirement specifies the exact text "Merge this change?" to be asked to the human. This is used as written in the `HITL` construct.

6. **Automatic decision criteria**: `AUTO` permits automatic resolution only when the agent can determine one single answer from the list based on available information and applicable criteria (per the **AUTO** section). Uncertainty in the determination means the human must be asked.
