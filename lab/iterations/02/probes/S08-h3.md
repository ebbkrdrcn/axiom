# Analysis of DSL Execution

## Program
```
REQUIRE staging-credentials
DELEGATE deployment
EMIT deployment-log
```

**Context:** The runtime determines that staging-credentials cannot be obtained.

---

## Question 1: What happens at `REQUIRE staging-credentials`?

Execution ends immediately.

According to the specification section on `REQUIRE`:

> | Situation | What happens |
> |---|---|
> | The runtime determines the item cannot be obtained, and there is no `FALLBACK` | Execution ends, as with `STOP`. |

Since the `REQUIRE` statement has no `→ FALLBACK` clause indented under it, and the runtime determines the item cannot be obtained, the execution ends as if `STOP` were called.

---

## Question 2: Is `DELEGATE deployment` executed?

**No.**

Execution does not reach the `DELEGATE deployment` statement because execution ends at the `REQUIRE staging-credentials` statement.

---

## Question 3: Is `EMIT deployment-log` executed?

**No.**

Execution does not reach the `EMIT deployment-log` statement because execution has already ended at the `REQUIRE` statement.

---

## Question 4: What exactly should the executing agent do?

The executing agent must:

1. **Validate the program** — Check all validity rules V1–V10 (the program is valid).

2. **Execute statements in order** — Process one statement at a time:
   - Execute `REQUIRE staging-credentials`

3. **Apply the REQUIRE rule** — According to the specification:
   > The agent MUST NOT assume, fabricate, or substitute the item. It MUST NOT skip the `REQUIRE` or continue in a degraded mode.

4. **End execution** — Since the runtime determines the item cannot be obtained and there is no `FALLBACK` defined, execution ends immediately (as with `STOP`). No further statements are executed.

5. **Report** — The agent should indicate that execution ended due to an unavailable required item with no fallback recovery path defined.

The specification makes clear: "Never invent. Results come from actors, outcomes from `VERIFY` or `HITL`, answers from humans (or from the agent only under `AUTO`), and events from the runtime." The agent cannot proceed without the required staging-credentials.
