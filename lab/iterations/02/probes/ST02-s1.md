# Modified DSL program

## Changes made

1. **Deploy decision may be made by the agent.** Added `AUTO` directly before `HITL:deploy[...]`. Per the spec, `AUTO` applies only to the one `HITL` it directly precedes on the same line (rule V5), and it is valid here because `HITL:deploy[approved, rejected](...)` is a decision form with a name and an answer list. This lets the agent establish `deploy.approved` or `deploy.rejected` itself when the decision is certain and within its authority; otherwise the human is asked, exactly as before (see the "Who decides a `HITL`" table and the `AUTO` section).
2. **Announce decision stays human-only.** No `AUTO` was added to `HITL:announce[...]`; it remains a plain `HITL`, so the agent MUST NOT answer it — only the human can.
3. **No usable answer for the announce question → "Quiet" and stop.** Added a `→ FALLBACK` block directly under `HITL:announce[...]`, per the `FALLBACK` rules: it applies when the response is insufficient or unavailable, runs instead of the normal flow, and must end in `STOP` or `BREAK` (rule V8). The fallback flow is `TRANSITION "Quiet"` then `STOP`.

Nothing else was changed: the `DELEGATE deployment-plan` line, both `WHEN deploy.*` branches, the `HITL:announce` answer list and question text, and the `WHEN announce.yes` branch are all left exactly as written.

## Assumptions

The specification fully determines this task; no gap-filling was required. One point worth making explicit: the instruction "the announce decision stays human-only" is satisfied simply by *not* adding `AUTO` to `HITL:announce` — the base `HITL` form is already human-only by rule ("the agent MUST NOT answer" unless marked `AUTO`), so no additional keyword or construct was needed to enforce that.

## Modified program

```text
DELEGATE deployment-plan
AUTO HITL:deploy[approved, rejected]("Deploy the plan?")
WHEN deploy.approved
  → DELEGATE deployment
WHEN deploy.rejected
  → TRANSITION "Replanning"
HITL:announce[yes, no]("Announce the release publicly?")
  → FALLBACK
      → TRANSITION "Quiet"
      → STOP
WHEN announce.yes
  → EMIT announcement
```
