**Trace:**

1. DELEGATE release-notes -> done
2. HITL:notes[approved, rejected]("Approve the release notes?") -> outcome notes.approved
3. WHEN notes.approved -> true: run flow
4. TRANSITION "Published" -> state = "Published"
5. EMIT release-notes -> done
6. WHEN notes.rejected -> false: skip
7. (end of program) -> end

**Final state:** `Published`

**Explanation:** The human's response "Approved." clearly selects the `approved` answer from the list. This is a usable response, so execution continues normally. The first `WHEN` is true and executes its flow. The second `WHEN` is false because `notes.rejected` is not established.
