# DSL Snippet Validation

## Snippet 1
```
AUTO HITL:deploy[yes, no]("Deploy to production?")
WHEN deploy.yes
  → EMIT deployment
```
**VALID**

The `AUTO` keyword is immediately followed on the same line by a decision `HITL` with name and answer list. This satisfies rule V5. The `WHEN` condition tests an outcome (`deploy.yes`) that the `HITL` can produce.

## Snippet 2
```
AUTO DELEGATE implementation
VERIFY implementation
```
**INVALID - Rule V5**

`AUTO` MUST be immediately followed on the same line by a decision `HITL:<name>[…]`. The specification explicitly lists `AUTO DELEGATE implementation` as an invalid example. `AUTO` applies only to decision HITLs and is not a standalone statement that can modify other keywords.

## Snippet 3
```
HITL:deploy[yes, no]("Deploy to production?") AUTO
WHEN deploy.yes
  → EMIT deployment
```
**INVALID - Rule V5**

`AUTO` must be written directly **before** `HITL` on the same line. The specification states: "`AUTO` is written directly before `HITL`, on the same line." This snippet has `AUTO` appearing after the `HITL`, which violates the required form.

## Snippet 4
```
AUTO
HITL:deploy[yes, no]("Deploy to production?")
```
**INVALID - Rule V5**

`AUTO` and `HITL` appear on separate lines. Rule V5 requires `AUTO` to be immediately followed **on the same line** by a decision `HITL`. Placing them on consecutive lines does not satisfy this requirement.
