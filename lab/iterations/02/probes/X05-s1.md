# Validity of the four snippets

## Snippet 1

```
AUTO HITL:deploy[yes, no]("Deploy to production?")
WHEN deploy.yes
  → EMIT deployment
```

**VALID.**

- `AUTO` is written directly before `HITL:deploy[yes, no](...)`, on the same line, and that `HITL` is a decision form with a name and a non-empty, non-repeating answer list (`yes`, `no`) — this satisfies the requirement of rule **V5** (`AUTO` MUST be immediately followed, on the same line, by a decision `HITL:<name>[…]`).
- `WHEN deploy.yes` tests the subject/outcome pair `deploy.yes`. The program contains `HITL:deploy[yes, no]` listing `yes` as one of its answers, so the outcome is one the program can produce — rule **V6** is satisfied (no violation).
- No `FALLBACK` is attached to the `HITL`, which is allowed: a `FALLBACK` is optional (`[fallback]` in the grammar), it only becomes relevant if the response is insufficient/unavailable.
- Indentation is consistent with the `WHEN`/`→` rules (Indentation and scope, rule 4/5): the `→ EMIT deployment` line is a child of `WHEN`.

No validity rule (V1–V10) is broken.

## Snippet 2

```
AUTO DELEGATE implementation
VERIFY implementation
```

**INVALID — rule V5.**

`AUTO` MUST be immediately followed, on the same line, by a decision `HITL:<name>[…]`. Here `AUTO` is followed by `DELEGATE implementation`, not by a `HITL`. The specification even lists this exact construct verbatim as an explicit `invalid` example:

```invalid
AUTO DELEGATE implementation
```

This directly matches rule **V5** (`AUTO` is not immediately followed, on the same line, by a decision `HITL:<name>[…]`).

## Snippet 3

```
HITL:deploy[yes, no]("Deploy to production?") AUTO
WHEN deploy.yes
  → EMIT deployment
```

**INVALID — rule V5.**

The grammar for `hitl` requires the optional `"AUTO"` token to appear *before* `"HITL:"` on the line: `hitl = ( [ "AUTO" ] , "HITL:" , identifier , "[" , ... )`. The prose confirms this: "`AUTO` is written directly before `HITL`, on the same line." In this snippet, `AUTO` appears *after* the `HITL:deploy[...](...)` construct instead of before it, so `AUTO` is not immediately followed, on the same line, by a decision `HITL:<name>[…]` (it is followed by nothing — end of line). This violates rule **V5**.

(Note: even setting aside V5, this ordering isn't a recognized form under the grammar's `hitl` production at all, since `AUTO` can only occur in the leading position; the clearest applicable named rule is V5.)

## Snippet 4

```
AUTO
HITL:deploy[yes, no]("Deploy to production?")
```

**INVALID — rule V5.**

`AUTO` and `HITL:deploy[...]` are written on two separate lines. The specification requires `AUTO` to be "written directly before `HITL`, on the same line," and the grammar treats `[ "AUTO" ]` and `"HITL:" ...` as tokens of the same `hitl` production line (there is no `NL` between them in the grammar). Since `AUTO` here is not immediately followed, on the same line, by a decision `HITL:<name>[…]` (it is followed by a line break, then the `HITL` on the next line), this violates rule **V5**.

This is also consistent with the spirit of the explicitly given invalid example:

```invalid
AUTO
  WHEN decision.uncertain
    → HITL("Approve?")
```

which likewise shows `AUTO` not immediately followed on the same line by a decision `HITL`.

# Summary

| Snippet | Verdict | Rule |
|---|---|---|
| 1 | VALID | — (satisfies V5 and V6; no rule broken) |
| 2 | INVALID | V5 (`AUTO` not immediately followed on the same line by a decision `HITL`) |
| 3 | INVALID | V5 (`AUTO` must precede `HITL` on the same line; here it follows it) |
| 4 | INVALID | V5 (`AUTO` and `HITL` are on separate lines, not the same line) |

**Note on assumptions:** The specification does not give an explicit named rule solely for "`AUTO` placed after `HITL` on the same line" (Snippet 3) as distinct from "`AUTO` and `HITL` on separate lines" (Snippet 4); both are treated here as instances of rule V5's general requirement ("`AUTO` is not immediately followed, on the same line, by a decision `HITL:<name>[…]`"), since in both cases the token immediately following `AUTO` on its own line is not a decision `HITL`. This reading is directly supported by the grammar production `hitl = ( [ "AUTO" ] , "HITL:" , ... )`, which fixes `AUTO` as strictly preceding `HITL` with no line break, and is treated as determinate rather than an assumption requiring further guesswork.
