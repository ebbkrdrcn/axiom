# Modified go_harness Program

```
DELEGATE deployment-plan
AUTO HITL:deploy[approved, rejected]("Deploy the plan?")
WHEN deploy.approved
  → DELEGATE deployment
WHEN deploy.rejected
  → TRANSITION "Replanning"
HITL:announce[yes, no]("Announce the release publicly?")
  → FALLBACK
      → TRANSITION "Quiet"
      → STOP
WHEN announce.yes
  → EMIT announcement
```

## Changes Made

1. **Line 2**: Added `AUTO` before `HITL:deploy` to allow the agent to make the deploy decision automatically when it is clearly determined, per the AUTO specification rule.

2. **Lines 8–10**: Added a `→ FALLBACK` clause under `HITL:announce` that executes when no usable answer is obtained. The fallback transitions to state "Quiet" and stops execution, fulfilling requirement (2).

3. **Lines 11**: The announce decision remains human-only (no AUTO modifier), fulfilling requirement (1).

All other statements and structure remain unchanged.
