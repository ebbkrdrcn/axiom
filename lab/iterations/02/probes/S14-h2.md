# Execution Trace and Final State

## Program
```
FORK
  → DELEGATE unit-tests
      VERIFY unit-tests
  → DELEGATE integration-tests
      VERIFY integration-tests
JOIN
WHEN unit-tests.accepted
  → TRANSITION "Ready"
WHEN integration-tests.rejected
  → TRANSITION "Debugging"
```

## Step-by-Step Execution

```trace
1. FORK -> branches started
2. DELEGATE unit-tests -> done
3. VERIFY unit-tests -> outcome unit-tests.accepted
4. DELEGATE integration-tests -> done
5. VERIFY integration-tests -> outcome integration-tests.rejected
6. JOIN -> joined
7. WHEN unit-tests.accepted -> true: run flow
8. TRANSITION "Ready" -> state = "Ready"
9. WHEN integration-tests.rejected -> true: run flow
10. TRANSITION "Debugging" -> state = "Debugging"
11. (end of program) -> end
```

## Final State
`Debugging`

## Explanation

- **Step 1:** Both branches of the `FORK` start concurrently. Branch 1 handles unit-tests; Branch 2 handles integration-tests.
- **Steps 2-3:** Branch 1 completes: `DELEGATE unit-tests` finishes, then `VERIFY unit-tests` establishes the outcome `unit-tests.accepted`.
- **Steps 4-5:** Branch 2 completes: `DELEGATE integration-tests` finishes, then `VERIFY integration-tests` establishes the outcome `integration-tests.rejected` (this finishes later than Branch 1, as specified in the events).
- **Step 6:** `JOIN` waits for all branches to complete. Both branches are now done, so the join completes.
- **Steps 7-8:** The first `WHEN` is evaluated. Since `unit-tests.accepted` is true, the flow runs and sets the state to `"Ready"`.
- **Steps 9-10:** The second `WHEN` is evaluated. Since `integration-tests.rejected` is true, the flow runs and sets the state to `"Debugging"`.
- **Step 11:** The program ends normally.

Per the specification, each `TRANSITION` replaces the previous state, and "the most recently executed one wins." Since `TRANSITION "Debugging"` is the last one executed, the final process state is **`Debugging`**.
