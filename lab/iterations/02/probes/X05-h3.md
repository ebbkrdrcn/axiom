# go_harness DSL Validation

## Snippet 1
```
AUTO HITL:deploy[yes, no]("Deploy to production?")
WHEN deploy.yes
  → EMIT deployment
```
**VALID**

This snippet conforms to the `AUTO` specification. `AUTO` is written directly before the HITL decision on the same line (specification line 387), which is the required form. The HITL is a decision with a name (`deploy`) and an answer list (`[yes, no]`). The subsequent `WHEN` tests a valid outcome `deploy.yes` that the HITL can establish. No validity rules are violated.

---

## Snippet 2
```
AUTO DELEGATE implementation
VERIFY implementation
```
**INVALID (V5)**

Rule V5 (line 560-561) states: "`AUTO` is not immediately followed, on the same line, by a decision `HITL:<name>[…]`"

`AUTO` can only precede a decision HITL, not other statements. The specification explicitly states at line 387: "`AUTO` is written directly before `HITL`, on the same line. It applies only to that one `HITL`, which MUST be a decision (with a name and an answer list)."

Applying `AUTO` to `DELEGATE` is invalid. The specification also shows at line 415 an example of this invalid pattern: `AUTO DELEGATE implementation`.

## Snippet 3
```
HITL:deploy[yes, no]("Deploy to production?") AUTO
WHEN deploy.yes
  → EMIT deployment
```
**INVALID (V5)**

Rule V5 states that `AUTO` MUST be immediately followed on the same line by a decision HITL. In this snippet, `AUTO` appears after the HITL statement, not before it. The specification at line 387 requires: "`AUTO` is written directly before `HITL`, on the same line."

The placement of `AUTO` at the end of the line is not valid—it must precede the HITL.

---

## Snippet 4
```
AUTO
HITL:deploy[yes, no]("Deploy to production?")
```
**INVALID (V5)**

Rule V5 requires that `AUTO` be written directly before the HITL **on the same line**. In this snippet, `AUTO` is on a separate line from the HITL. The specification at line 387 explicitly states: "`AUTO` is written directly before `HITL`, on the same line."

This violates the requirement that they appear together on a single line.
