## Explanation

The program follows this flow:

1. **Iteration 1**: The `WHEN draft.accepted` condition is false because no outcome has been established yet (rule 7: before anything establishes it, every `WHEN` on it is false). The loop executes `DELEGATE draft` and then `VERIFY draft`, which establishes `draft.rejected`. The loop repeats.

2. **Iteration 2**: The `WHEN draft.accepted` condition is still false because the current outcome is `draft.rejected`. The loop executes `DELEGATE draft` and then `VERIFY draft`, which now establishes `draft.accepted`. The loop repeats.

3. **Iteration 3**: The `WHEN draft.accepted` condition is now true because the outcome is `draft.accepted`. The flow executes `BREAK`, which exits the loop immediately. Execution continues with `TRANSITION "Done"`, setting the final state.

4. The program ends normally after the last top-level statement.
