# Execution Trace: First Two Iterations

## First Iteration

1. **DELEGATE build** → The actor performs the build work and delivers a result.
2. **VERIFY build** → The build result is evaluated. The specification states that in every iteration, `VERIFY build` establishes `build.rejected`.
3. **WHEN build.accepted** → The condition tests whether the latest outcome of `build` is `accepted`. However, the latest outcome is `rejected` (established in step 2), so the condition is **false**.
4. The WHEN body is skipped (the `→ BREAK` is not executed).
5. **End of loop body** → According to the specification's execution rules, when the last statement of the loop body is done, the next iteration starts at the first statement of the body.

## Second Iteration

1. **DELEGATE build** → The actor performs the build work and delivers a result.
2. **VERIFY build** → The build result is evaluated and establishes `build.rejected` (as stated: "in every iteration, `VERIFY build` establishes `build.rejected`").
3. **WHEN build.accepted** → The condition tests whether the latest outcome is `accepted`. The latest outcome remains `rejected` (from step 2), so the condition is **false**.
4. The WHEN body is skipped (the `→ BREAK` is not executed).
5. **End of loop body** → The loop continues, returning to the first statement.

## When is `EMIT build-report` Executed?

**`EMIT build-report` is never executed.**

According to the specification, `EMIT build-report` is at the same indentation level as `LOOP:build`, meaning it executes only after the loop ends. The loop ends when:
- `BREAK` is executed (which leaves the innermost `LOOP` immediately), or
- `STOP` is executed (which ends the entire execution)

In this program, neither of these occurs because:
- The `BREAK` statement is inside the `WHEN build.accepted` flow, which only runs when `build.accepted` is true
- Since `VERIFY build` establishes `build.rejected` in every iteration, the `WHEN build.accepted` condition is always false
- Therefore, `BREAK` is never executed and the loop continues indefinitely

The program enters an infinite loop and never reaches `EMIT build-report`.
