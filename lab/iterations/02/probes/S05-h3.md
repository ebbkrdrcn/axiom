# Snippet Validity Analysis

## Snippet A: INVALID
**Rule violated:** V5
**Reason:** `AUTO` is not immediately followed, on the same line, by a decision `HITL:<name>[…]`. The `AUTO` appears on its own line instead of on the same line as the HITL statement.

## Snippet B: INVALID
**Rule violated:** V2
**Reason:** `BREAK` is not inside a `LOOP`. The BREAK statement appears outside of any loop construct, which is not permitted.

## Snippet C: VALID
**Reason:** 
- `AUTO HITL:approve[yes, no]("Approve release?")` is properly formed with AUTO on the same line as the HITL (satisfies V5)
- `WHEN approve.yes` correctly tests an outcome that can be established by the HITL
- `→ EMIT release` is a valid flow statement

## Snippet D: INVALID
**Rule violated:** V8
**Reason:** The last item of a fallback flow is not `STOP` or `BREAK`. The fallback flow ends with `→ TRANSITION "Blocked"` but contains no STOP or BREAK to terminate it. According to rule V8, fallback flows MUST end with either STOP or BREAK.
