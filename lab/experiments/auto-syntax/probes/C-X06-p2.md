# Answer

## 1. Which of the two decisions may the agent make by itself, and under what condition?

Only the **`wording`** decision may be resolved by the agent itself. The `wording` `HITL` is the only one marked with `→ AUTO`:

```text
HITL:wording("Short or detailed release notes?")
  → AUTO
```

The `release` decision (`HITL:release("Approve the release?")`) carries no `→ AUTO` marker. Per the specification, "`HITL` must not be silently replaced by an agent decision unless that `HITL` is explicitly marked with `AUTO`." Since `release` is not marked `AUTO`, the agent may never resolve it itself, under any condition — a human must always be asked.

For `wording`, even though it is marked `AUTO`, the agent may only resolve it automatically **under the condition that the decision is sufficiently determined**: the agent can determine a single protocol-compatible answer (`short` or `detailed`) from the available information and applicable criteria, with no ambiguity, contradiction, missing information, unresolved interpretation, or lack of authority. If that condition holds, the agent establishes `wording.short` or `wording.detailed` itself, exactly as if a human had answered, and no human is asked. If the condition does not hold, the human is asked instead (see Q3).

## 2. All automated checks are green and the agent is highly confident the release should be approved. May it answer "Approve the release?" itself?

No. The `release` `HITL` has no `→ AUTO` attached at all, so `AUTO`'s "sufficiently determined" test doesn't even apply to it — automatic resolution was never enabled for this decision in the first place. Per the spec, a `HITL` "must not be silently replaced by an agent decision unless that `HITL` is explicitly marked with `AUTO`," and this one isn't. Additionally, the spec explicitly states that "a confidence score alone does not establish certainty," reinforcing that high confidence from checks would not be sufficient even if `AUTO` were present. So regardless of how confident the agent is or how green the checks are, the human must be asked "Approve the release?", and execution waits there until a usable response (or a `FALLBACK`, if one existed — here none is defined for `release`) is available.

## 3. If the wording decision is not clearly determined, what happens?

Per the `AUTO` execution table, when `AUTO` is present but the decision is uncertain (or outside the agent's authority): "The human is asked, as for a `HITL` without `AUTO`." So:

- The agent does not guess or fabricate an answer.
- The human is asked the message "Short or detailed release notes?".
- If a usable response arrives — i.e., one of the answers tested by the following `WHEN` constructs, `short` or `detailed` — the corresponding outcome (`wording.short` or `wording.detailed`) is established, and execution continues with the statement after the `HITL` construct (the two `WHEN wording.*` checks, and then on to the `release` `HITL`).
- If the response is unavailable (none arrives) or insufficient (e.g., an off-topic or unusable reply), the `FALLBACK` flow would normally be used — but **this `wording` `HITL` has no `→ FALLBACK` attached** in the given program.

**Note — underdetermined by the specification:** the spec states a `HITL` "waits ... until either a usable response is available or its `FALLBACK` flow is used," and that `FALLBACK` is optional (per the grammar, the `FALLBACK` branch of the `hitl` rule is bracketed as optional). It does not explicitly say what happens when a response is unavailable/insufficient *and* no `FALLBACK` is defined. I assume, by the only continuation condition the spec gives ("a usable response is available or its `FALLBACK` flow is used"), that with no `FALLBACK` present the flow simply remains suspended at the `wording` `HITL` — analogous to `WAIT`, which the spec says has no timeout and remains suspended if its condition never arrives — until a usable response (`short` or `detailed`) is eventually given. The spec does not authorize the agent to invent an answer in this situation, and does not define any other automatic escalation or termination for a `FALLBACK`-less `HITL`.
