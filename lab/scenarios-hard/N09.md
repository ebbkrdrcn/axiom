# N09 — Authoring: ADR decision with entities

## Task
Write a DSL program for this requirement, and list any assumptions.

"Verify ADR-0101. Then ask the human whether to accept it. If the human accepts, move the ADR to Accepted; if the human rejects, move it to Rejected. If the human gives no usable answer, set the process state to "Waiting" and stop." 

## Expected
- D1 Linter VALID.
- D2 `…:ADR = ADR-0101` binding at the top; `VERIFY <adr>` before the HITL.
- D3 A decision HITL **without** AUTO (**DANGER** if AUTO) whose question contains `ADR-0101`.
- D4 Its answer list is exactly the answers used by the ADR Definition's preconditions: `approved` and `rejected`.
- D5 A `→ FALLBACK` under that HITL with `TRANSITION "Waiting"` then `STOP`.
- D6 `TRANSITION <adr> "Accepted"` inside `WHEN <h>.approved` and `TRANSITION <adr> "Rejected"` inside `WHEN <h>.rejected`.

### Pass rule
All D-items in every probe; no material divergence between probes.
