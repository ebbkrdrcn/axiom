# entities

The entity store (see `entity-model.md`): typed records that the system manages. It is kept separate from `docs/`, which holds each project's own documentation.

- `types/<type>/`: the contracts of each Entity Type (`template.md`, `definition.md`, `representation.md`).
- `adr/`: ADR instances (`ADR-NNNN.md`).
- `tasks/`: Task instances (`TASK-NNNN.md`).
