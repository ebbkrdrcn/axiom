# Terminology: process state, entity status, entity data

## Context

The DSL's `TRANSITION "<state>"` and the Entity Model's "State" used the same word for different things.

## Decision

**State** means only the process state, set by `TRANSITION "<state>"`, which is `none` before the first TRANSITION. An entity has **data** (its field and section values) and a **status** (the part of the data governed by its Definition's transitions).

## Consequences

- `entity-model.md` uses "Data" where it used "State".

## Alternatives Considered

- Qualifying every use ("process state" / "entity state"): error-prone for literal readers.
